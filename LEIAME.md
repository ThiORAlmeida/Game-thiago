# Como gerar o APK (sem instalar nada)

1. Crie um repositório novo no GitHub (pode ser privado).
2. Envie todo o conteúdo desta pasta (inclusive a pasta oculta .github).
3. Abra a aba Actions, escolha "Gerar APK" e clique em Run workflow.
4. Em uns 5 minutos, baixe o arquivo tycoon-energia-apk no fim da execução e extraia o app-debug.apk.
5. No celular, permita instalar apps de fontes desconhecidas e abra o APK.
